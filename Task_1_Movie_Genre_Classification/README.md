## 🎬 Project Overview
In the entertainment industry, categorizing movies into correct genres automatically is highly beneficial for recommendation engines and search indexing. This project utilizes **Natural Language Processing (NLP)** and **Supervised Machine Learning** techniques to classify unseen movie plots into standard genres.

### Key Highlights:
* **Custom Dataset:** Uses a benchmark collection of 100 well-known Indian Movies (spanning Bollywood classics, South Indian blockbusters, and modern releases up to 2026).
* **Multi-Class Classification:** Categorizes films into core genres: `Action`, `Romantic`, `Horror`, `Comedy`, `Drama`, `Thriller`, and `Sci-Fi`.
* **State-of-the-Art Pipeline:** Integrates robust text preprocessing, numerical feature extraction, and optimized classification.

## 📊 Dataset Structure
The dataset is structured inside the `dataset/train_data.txt` file using a standard triple-colon delimiter (` ::: `) with the following format:
`MOVIE_ID ::: MOVIE_TITLE ::: GENRE ::: PLOT_DESCRIPTION`

### Sample Data Points:
1. `Sholay (1975) ::: action ::: In the village of Ramgarh, a retired police officer hires two notorious convicts...`
2. `Dilwale Dulhania Le Jayenge (1995) ::: romantic ::: A young rich boy meets a traditional girl on a European vacation...`
3. `Kalki 2898 AD (2024) ::: sci-fi ::: In a dystopian futuristic world, a modern incarnation of a warrior god descends...`

## ⚙️ Technical Methodology & Workflow

The system follows a modular machine learning pipeline implemented entirely in a Jupyter Notebook:

### 1. Data Cleaning & Text Preprocessing
Raw textual data is heavily polluted with noise. The text is passed through a customized cleaning function that:
* Converts all plot summaries into lowercase letters to maintain uniformity.
* Uses regular expressions (`re`) to strip out special characters, symbols, and numerical values.
* Automatically filters out standard English stop words (like *the, is, and, at, which*) that carry no predictive weight.

### 2. Feature Extraction (TF-IDF Vectorization)
Computers cannot understand raw strings, so text must be converted into numerical vectors. 
* We utilize the **TF-IDF (Term Frequency - Inverse Document Frequency)** vectorizer.
* This algorithm evaluates how important a word is to a specific movie description relative to the entire dataset of 100 movies, assigning higher mathematical weights to rare and highly descriptive words.

### 3. Model Architecture (Logistic Regression)
* For multi-class text classification, a **Logistic Regression** model is utilized. 
* It computes the probability scores for each genre based on the TF-IDF feature matrix and maps the text to the genre with the highest probability. It provides exceptional speed and accuracy for text-heavy datasets.
